# 붓 커서와 클래식 배경음악 설계

## 목표

Platen의 입력 커서를 기존 도형 순환 대신 붓 모양으로 표현하고, 글을 쓰는 동안 Web Audio API로 합성한 피아노풍 클래식 배경음악을 재생한다.

## 범위

- 수정 파일: `index.html`
- 기존 `#cursorAnchor` 요소와 입력·한글 조합·램프·타자음 기능을 유지한다.
- 외부 라이브러리, 외부 음원 URL, 별도 빌드 도구는 추가하지 않는다.
- 배경음악은 브라우저 자동재생 제한을 고려해 사용자 클릭 이후 시작한다.
- 커밋과 push는 사용자의 화면 확인 전에는 하지 않는다.

## 커서 설계

- 기존 `data-cursor-shape` 순환 상태와 네 가지 도형 스타일을 제거한다.
- `#cursorAnchor`의 레이아웃 폭·높이는 유지한다.
- CSS pseudo-element 두 개로 붓 손잡이와 붓털을 표현한다.
- 작성 이벤트마다 `brush-stroke` 클래스를 잠깐 추가해 붓이 짧게 기울고 되돌아오는 애니메이션을 재생한다.
- `prefers-reduced-motion: reduce`에서는 애니메이션을 제거하지만 붓 모양은 유지한다.
- 타격 효과와 램프 위치 계산은 기존 텍스트 노드를 계속 사용한다.

## 배경음악 설계

- 기존 `TypewriterAudio`와 분리된 `AmbientMusic` 클래스를 추가한다.
- `AudioContext`, 마스터 gain, 두 개의 oscillator를 사용해 피아노풍 음색을 만든다.
- C장조 기반의 짧은 클래식 아르페지오 패턴을 반복하고, 각 음은 attack·release envelope로 자연스럽게 줄인다.
- 사용자 조작 후에만 `AudioContext.resume()`과 스케줄러를 시작한다.
- HUD에 `배경음악 ▶` / `배경음악 ⏸` 버튼을 추가한다.
- 음악 볼륨은 낮은 기본값으로 설정해 타자음과 입력 경험을 방해하지 않게 한다.
- 일시정지 시 스케줄러를 중지하고 gain을 닫으며, 다시 시작하면 현재 시점부터 패턴을 재생한다.
- 모션 감소 설정과 음악 재생은 독립적이다. 사용자가 음악을 켠 경우에는 모션 설정과 관계없이 음악을 재생한다.

## 입력·상태 연결

- 기존 `advanceCursorShape()` 호출을 `triggerBrushStroke()` 호출로 교체한다.
- 공백·Enter·자모 입력 모두 같은 작성 경로에서 붓질 애니메이션을 실행한다.
- 백스페이스는 기존처럼 내용을 지우며 붓질 애니메이션을 실행하지 않는다.
- 배경음악 버튼·자동 타이핑 버튼·종이 클릭은 기존 이벤트 전파와 포커스 동작을 유지한다.
- 배경음악 초기화는 `sound.init()`과 분리하되, 첫 사용자 클릭으로 활성화할 수 있게 한다.

## 오류 처리

- Web Audio API를 사용할 수 없는 환경에서는 음악 버튼을 비활성화하고 기존 타자음과 앱 기능은 계속 동작한다.
- oscillator 생성·스케줄링 실패는 앱 전체 입력을 막지 않고 음악만 중단한다.
- 음원 파일 네트워크 요청을 하지 않으므로 로컬 서버·GitHub Pages에서 같은 방식으로 동작한다.

## 검증

1. HTML 내부 JavaScript 문법 검사
2. 붓 커서 선택자와 `triggerBrushStroke()` 호출 경로 정적 검사
3. 브라우저에서 커서가 붓 모양으로 보이고 작성 시 붓질 애니메이션이 실행되는지 확인
4. 배경음악 버튼 클릭 후 음악 재생·일시정지 확인
5. 자동재생 차단 상태에서 페이지가 오류 없이 열리는지 확인
6. 기존 한글 조합, 자동 타이핑, 타격음, 램프 기능 확인
7. `python3 -m http.server 8000` 재시작 후 HTTP 200과 브라우저 로딩 확인
8. 커밋·push 없이 작업 브랜치와 변경 상태 확인

## 완료 기준

- 커서가 네 가지 도형이 아닌 붓 모양으로 표시된다.
- 글자 작성 시 붓질 애니메이션이 실행된다.
- 사용자 클릭으로 클래식 배경음악을 시작·일시정지할 수 있다.
- 외부 음원·라이브러리·빌드 도구가 추가되지 않는다.
- 기존 기능이 유지되고 개발 서버에서 확인 가능하다.
